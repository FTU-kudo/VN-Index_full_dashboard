# Summary CSV Files

This directory contains processed flat files (CSV) generated by the pipeline for easy downstream consumption (e.g. by visualization tools or factor models).

## latest_prices.csv
Contains the most recent snapshot of price and trading data.

| Column | Type | Mô tả |
|---|---|---|
| stock_code | str | Mã CP |
| exchange | str | HSX/HNX/UPCOM |
| last_price | float | Giá khớp gần nhất (VND) |
| pct_change | float | % thay đổi so với giá tham chiếu |
| total_vol | float | Tổng khối lượng khớp lệnh |
| total_val | float | Tổng giá trị (VND) |
| ft_buy_vol | float | Nước ngoài mua (CP) |
| ft_sell_vol | float | Nước ngoài bán (CP) |

## latest_ratings.csv
Contains Yuanta's proprietary rating scores.

| Column | Type | Mô tả |
|---|---|---|
| stock_code | str | Mã CP |
| stock_rating | float | Điểm YSRadar (0–100) |
| recommendation | int | 1=Mua / 3=Giữ / 5=Bán |
| target_price | float | Giá mục tiêu Yuanta |
| fundamental_point | float | Điểm cơ bản (0-100) |
| technical_point | float | Điểm kỹ thuật (0-100) |
| trailing_stop | float | Giá cắt lỗ |

## factor_scores.csv
Contains the computed z-scores for various fundamental and technical factors.

| Column | Type | Mô tả |
|---|---|---|
| stock_code | str | Mã CP |
| ROE | float | Z-score cho ROE |
| ROA | float | Z-score cho ROA |
| PE | float | Z-score cho P/E |
| PB | float | Z-score cho P/B |
| composite | float | Trung bình có trọng số của các factors |

Z-scores được chuẩn hóa cross-sectional trên toàn vũ trụ cổ phiếu.
